## 📋 **IDENTIDADE VISUAL APLICADA**

### **🎨 Paleta de Cores Oficial**
Baseada no Manual de Identidade Visual e Comunicação - Madrilusa:

#### **Cores Primárias:**
- **Laranja Madrilusa:** `#F5A623` (RGB: 245, 166, 35)
- **Azul Turquesa:** `#4A90A4` (RGB: 74, 144, 164)

#### **Cores Neutras:**
- **Branco:** `#FFFFFF`
- **Cinzento Escuro:** `#333333` (texto corpo)
- **Cinzento Claro:** `#F5F5F5` (fundos alternativos)
- **Cinzento Médio:** `#666666` (texto secundário)

### **✍️ Tipografia Conforme Manual**
- **Família:** Open Sans, Helvetica Neue, sans-serif
- **H1 (Títulos principais):** 32px, bold, Azul Turquesa
- **H2 (Subtítulos):** 24px, semibold, Azul Turquesa  
- **Texto corpo:** 16px, regular, Cinzento Escuro
- **Texto secundário:** 14px, regular, Cinzento Médio
- **Espaçamento:** Sistema baseado em múltiplos de 8px

### **🏗️ Sistema de Layout**
- **Grelha modular** baseada no manual
- **Container máximo:** 1200px
- **Espaçamentos:** 8px, 16px, 24px, 32px, 48px
- **Margens:** 5% da largura total

## 🎨 **CLASSES CSS CRIADAS**

### **Sistema de Variáveis:**
```css
--app-primary: #F5A623;          /* Laranja Madrilusa */
--app-secondary: #4A90A4;        /* Azul Turquesa */
--app-font-family: 'Open Sans', 'Helvetica Neue', sans-serif;
--app-spacing-xs: 8px;           /* Sistema de espaçamento */
--app-spacing-sm: 16px;
--app-spacing-md: 24px;
```

### **Tipografia:**
```css

.app-text-body     /* Corpo: 16px, regular, Cinzento Escuro */
```

